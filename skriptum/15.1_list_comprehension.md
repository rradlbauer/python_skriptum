# 15.1 List Comprehension

## Lernziele

Nach diesem Kapitel kannst du ...

- erklären, was ein **Iterable** ist.
- mit einer **List Comprehension** neue Listen erzeugen.
- Werte beim Erzeugen einer Liste verändern.
- Elemente mit Bedingungen auswählen.
- Transformation und Filter kombinieren.
- zwischen einem Filter und einem `if ... else`-Ausdruck unterscheiden.
- Funktionen innerhalb einer List Comprehension verwenden.
- einfache verschachtelte List Comprehensions lesen und schreiben.
- entscheiden, wann eine List Comprehension sinnvoll ist und wann eine normale Schleife besser lesbar ist.

---

## Ausgangssituation

Eine kleine Wetterstation misst mehrmals täglich die Temperatur.

Die Messwerte werden in einer Liste gespeichert:

```python
temperaturen = [12.4, -1.2, 7.8, 0.0, -4.5, 15.1]
```

Für die weitere Auswertung sollen daraus unterschiedliche neue Listen entstehen.

Zum Beispiel möchten wir:

- alle Temperaturen runden,
- nur Frostwerte auswählen,
- Werte in Fahrenheit umrechnen,
- Messwerte als `"Frost"` oder `"kein Frost"` kennzeichnen.

Natürlich könnten wir jede dieser Aufgaben mit einer normalen `for`-Schleife lösen.

Python bietet für viele solcher Aufgaben aber eine kompakte Schreibweise: die **List Comprehension**.

---

# 1. Iterable

Bevor wir List Comprehensions verwenden, müssen wir verstehen, welche Daten überhaupt durchlaufen werden können.

Ein **Iterable** ist ein Objekt, dessen Elemente nacheinander durchlaufen werden können.

Das passiert beispielsweise in einer `for`-Schleife:

```python
zahlen = [10, 20, 30]

for zahl in zahlen:
    print(zahl)
```

Ausgabe:

```text
10
20
30
```

Die Liste `zahlen` ist ein Iterable.

Typische Iterables in Python sind:

- Listen
- Tupel
- Strings
- `range`-Objekte
- Mengen (`set`)
- Dictionaries

---

## Beispiele

### Liste

```python
farben = ["rot", "grün", "blau"]

for farbe in farben:
    print(farbe)
```

### Tupel

```python
punkt = (4, 7)

for wert in punkt:
    print(wert)
```

### `range`

```python
for zahl in range(5):
    print(zahl)
```

Ausgabe:

```text
0
1
2
3
4
```

### String

Auch ein String kann Zeichen für Zeichen durchlaufen werden:

```python
wort = "Python"

for zeichen in wort:
    print(zeichen)
```

### Dictionary

Auch ein Dictionary ist ein Iterable.

```python
person = {
    "name": "Anna",
    "alter": 16
}

for schluessel in person:
    print(schluessel)
```

Ausgabe:

```text
name
alter
```

Beim direkten Durchlaufen eines Dictionaries werden standardmäßig seine **Schlüssel** verwendet.

Schlüssel und Werte gemeinsam erhält man beispielsweise mit `items()`:

```python
for schluessel, wert in person.items():
    print(schluessel, wert)
```

---

## Iterable und Iterator

Die Begriffe **Iterable** und **Iterator** sind verwandt, aber nicht identisch.

Für dieses Kapitel reicht folgende Unterscheidung:

- Ein **Iterable** kann durchlaufen werden.
- Ein **Iterator** liefert beim Durchlaufen die einzelnen Werte.

Aus einer Liste kann mit `iter()` ein Iterator erzeugt werden:

```python
zahlen = [1, 2, 3]

iterator = iter(zahlen)

print(next(iterator))
print(next(iterator))
print(next(iterator))
```

Ausgabe:

```text
1
2
3
```

Für List Comprehensions ist vor allem wichtig:

> Ein Objekt, das mit einer `for`-Schleife durchlaufen werden kann, kann grundsätzlich auch als Datenquelle einer List Comprehension verwendet werden.

# 2. Eine neue Liste erzeugen

Angenommen, unsere Wetterstation soll zusätzlich gerundete Temperaturwerte speichern.

Mit einer normalen Schleife könnte das so aussehen:

```python
temperaturen = [12.4, -1.2, 7.8, 0.0, -4.5, 15.1]

gerundet = []

for temperatur in temperaturen:
    gerundet.append(round(temperatur))

print(gerundet)
```

Ausgabe:

```text
[12, -1, 8, 0, -4, 15]
```

Mit einer List Comprehension lässt sich dieselbe Aufgabe kompakter schreiben:

```python
gerundet = [
    round(temperatur)
    for temperatur in temperaturen
]

print(gerundet)
```

Auch hier entsteht:

```text
[12, -1, 8, 0, -4, 15]
```

---

# 3. Grundlegende Syntax

Die einfachste Form einer List Comprehension lautet:

```python
[ausdruck for element in iterable]
```

Die einzelnen Bestandteile haben folgende Bedeutung:

| Bestandteil | Bedeutung |
|---|---|
| `ausdruck` | Der Wert, der in die neue Liste aufgenommen wird |
| `element` | Variable für das jeweils aktuelle Element |
| `iterable` | Objekt, das durchlaufen wird |

Beispiel:

```python
[x * 2 for x in range(5)]
```

Ergebnis:

```text
[0, 2, 4, 6, 8]
```

Beim Lesen hilft folgende Reihenfolge:

1. `for x in range(5)`  
   → Welche Werte werden durchlaufen?
2. `x * 2`  
   → Was soll mit jedem Wert geschehen?

Man kann den Ausdruck also ungefähr so lesen:

> Für jedes `x` aus `range(5)` berechne `x * 2`.

---

# 4. Werte transformieren

Wenn aus jedem vorhandenen Wert ein neuer Wert berechnet wird, sprechen wir von einer **Transformation**.

Beispiel:

```python
zahlen = [1, 2, 3, 4]

verdoppelt = [
    zahl * 2
    for zahl in zahlen
]

print(verdoppelt)
```

Ausgabe:

```text
[2, 4, 6, 8]
```

Die ursprüngliche Liste bleibt dabei unverändert:

```python
print(zahlen)
```

Ausgabe:

```text
[1, 2, 3, 4]
```

Die List Comprehension erzeugt also eine **neue Liste**.

---

## Beispiel: Temperaturen in Fahrenheit

Die Wetterstation soll zusätzlich Werte in Fahrenheit anzeigen.

Die Umrechnungsformel lautet:

```text
F = C * 1.8 + 32
```

Mit einer List Comprehension:

```python
temperaturen = [0, 10, 20, 30]

fahrenheit = [
    temperatur * 1.8 + 32
    for temperatur in temperaturen
]

print(fahrenheit)
```

Ausgabe:

```text
[32.0, 50.0, 68.0, 86.0]
```

Für jede Temperatur wird genau ein neuer Wert erzeugt.

---

# 5. Elemente filtern

Nicht immer sollen alle Elemente übernommen werden.

Die Wetterstation soll beispielsweise nur Temperaturen unter 0 °C anzeigen.

Dafür kann eine List Comprehension eine Bedingung enthalten.

Die Syntax lautet:

```python
[ausdruck for element in iterable if bedingung]
```

Beispiel:

```python
temperaturen = [12.4, -1.2, 7.8, 0.0, -4.5, 15.1]

frostwerte = [
    temperatur
    for temperatur in temperaturen
    if temperatur < 0
]

print(frostwerte)
```

Ausgabe:

```text
[-1.2, -4.5]
```

Die Bedingung

```python
temperatur < 0
```

entscheidet, welche Werte übernommen werden.

Nur Werte, für die diese Bedingung `True` ergibt, landen in der neuen Liste.

---

## Beispiel: Gerade Zahlen

```python
gerade = [
    zahl
    for zahl in range(10)
    if zahl % 2 == 0
]

print(gerade)
```

Ausgabe:

```text
[0, 2, 4, 6, 8]
```

Hier wird überprüft, ob eine Zahl ohne Rest durch `2` teilbar ist.

---

# 6. Transformation und Filter kombinieren

Die Wetterstation soll nun nicht nur Frostwerte auswählen, sondern diese gleichzeitig in Fahrenheit umrechnen.

Wir benötigen daher zwei Schritte:

1. Nur Werte unter `0` auswählen.
2. Diese Werte in Fahrenheit umrechnen.

Beides kann in einer List Comprehension kombiniert werden:

```python
temperaturen = [12.4, -1.2, 7.8, 0.0, -4.5, 15.1]

frost_fahrenheit = [
    temperatur * 1.8 + 32
    for temperatur in temperaturen
    if temperatur < 0
]

print(frost_fahrenheit)
```

Ausgabe ungefähr:

```text
[29.84, 23.9]
```

Die List Comprehension kann man gedanklich so zerlegen:

```text
temperatur * 1.8 + 32
        ↑
   Transformation

for temperatur in temperaturen
        ↑
      Schleife

if temperatur < 0
        ↑
      Filter
```

---

# 7. Funktionen verwenden

Der Ausdruck einer List Comprehension kann auch ein Funktionsaufruf sein.

Die Umrechnung von Celsius in Fahrenheit könnte beispielsweise in einer Funktion gekapselt werden:

```python
def celsius_zu_fahrenheit(celsius):
    return celsius * 1.8 + 32
```

Danach kann die Funktion innerhalb einer List Comprehension verwendet werden:

```python
temperaturen = [0, 10, 20, 30]

fahrenheit = [
    celsius_zu_fahrenheit(temperatur)
    for temperatur in temperaturen
]

print(fahrenheit)
```

Ausgabe:

```text
[32.0, 50.0, 68.0, 86.0]
```

Das kann die Lesbarkeit verbessern, wenn die eigentliche Berechnung komplizierter wird.

# 8. Filtern oder einen bedingten Wert erzeugen?

Ein `if` kann bei List Comprehensions auf zwei unterschiedliche Arten vorkommen.

Diese beiden Varianten dürfen nicht verwechselt werden.

## Variante 1: Elemente filtern

```python
[
    temperatur
    for temperatur in temperaturen
    if temperatur < 0
]
```

Hier werden einige Elemente vollständig weggelassen.

Aus:

```python
temperaturen = [5, -2, 8, -4]
```

wird:

```text
[-2, -4]
```

## Variante 2: Für jedes Element einen passenden Wert erzeugen

Die Wetterstation soll nun für jeden Messwert eine Beschreibung erzeugen:

```python
temperaturen = [5, -2, 8, -4]
```

Gesucht ist:

```text
['kein Frost', 'Frost', 'kein Frost', 'Frost']
```

Dafür verwenden wir einen **bedingten Ausdruck**:

```python
status = [
    "Frost" if temperatur < 0 else "kein Frost"
    for temperatur in temperaturen
]

print(status)
```

Hier wird kein Element entfernt.

Für jede Temperatur entsteht genau ein neuer Wert.

Die allgemeine Form lautet:

```python
[
    wert_wenn_true if bedingung else wert_wenn_false
    for element in iterable
]
```

---

## Vergleich

### Filtern

```python
[
    temperatur
    for temperatur in temperaturen
    if temperatur < 0
]
```

Frage:

> Welche Elemente möchte ich behalten?

### Bedingter Ausdruck

```python
[
    "Frost" if temperatur < 0 else "kein Frost"
    for temperatur in temperaturen
]
```

Frage:

> Welcher Wert soll für jedes Element erzeugt werden?

---

# 9. Mehrzeilige Schreibweise

List Comprehensions müssen nicht in einer einzigen Zeile geschrieben werden.

Eine lange Zeile wie

```python
frost_fahrenheit = [temperatur * 1.8 + 32 for temperatur in temperaturen if temperatur < 0]
```

ist meist schlechter lesbar als:

```python
frost_fahrenheit = [
    temperatur * 1.8 + 32
    for temperatur in temperaturen
    if temperatur < 0
]
```

Beide Varianten sind gleichbedeutend.

> Gute Lesbarkeit ist wichtiger als möglichst kurzer Code.

---

# 10. Verschachtelte List Comprehensions

Listen können selbst wieder Listen enthalten.

Ein Beispiel ist eine Multiplikationstabelle:

```python
tabelle = [
    [1, 2, 3],
    [2, 4, 6],
    [3, 6, 9]
]
```

Eine solche Struktur kann mit zwei verschachtelten Schleifen erzeugt werden:

```python
tabelle = []

for x in range(1, 4):
    zeile = []

    for y in range(1, 4):
        zeile.append(x * y)

    tabelle.append(zeile)
```

Mit List Comprehensions kann dieselbe Struktur so erzeugt werden:

```python
tabelle = [
    [x * y for y in range(1, 4)]
    for x in range(1, 4)
]

print(tabelle)
```

Ausgabe:

```text
[
    [1, 2, 3],
    [2, 4, 6],
    [3, 6, 9]
]
```

Die innere List Comprehension erzeugt jeweils eine Zeile.

Die äußere List Comprehension erzeugt daraus die gesamte Tabelle.

---

# 11. Eine verschachtelte Liste flach machen

Gegeben ist eine Liste mit mehreren Unterlisten:

```python
messreihen = [
    [12.4, 13.1],
    [14.0, 13.7],
    [11.9, 12.2]
]
```

Gesucht ist eine einzige Liste:

```text
[12.4, 13.1, 14.0, 13.7, 11.9, 12.2]
```

Mit normalen Schleifen:

```python
alle_messwerte = []

for messreihe in messreihen:
    for messwert in messreihe:
        alle_messwerte.append(messwert)
```

Mit einer List Comprehension:

```python
alle_messwerte = [
    messwert
    for messreihe in messreihen
    for messwert in messreihe
]

print(alle_messwerte)
```

Die Reihenfolge der `for`-Teile entspricht dabei der Reihenfolge der normalen Schleifen.

---

# 12. Wann sind List Comprehensions sinnvoll?

List Comprehensions eignen sich besonders für einfache Aufgaben wie:

- Werte verändern,
- Elemente auswählen,
- Transformation und Filter kombinieren,
- neue Listen aus vorhandenen Daten erzeugen.

Beispiele:

```python
quadrate = [x ** 2 for x in zahlen]
```

```python
positive_zahlen = [x for x in zahlen if x > 0]
```

```python
quadrate_positiver_zahlen = [
    x ** 2
    for x in zahlen
    if x > 0
]
```

## Wann ist eine normale Schleife besser?

Eine normale Schleife ist oft besser lesbar, wenn

- mehrere komplizierte Bedingungen vorkommen,
- mehrere Berechnungen pro Element notwendig sind,
- Zwischenergebnisse benötigt werden,
- Ausgaben innerhalb der Verarbeitung erfolgen,
- die List Comprehension zu schwer verständlich wird.

> Eine List Comprehension ist dann gut, wenn sie den Code einfacher macht – nicht nur kürzer.

# 13. Typische Fehler

## Ausdruck vergessen

Falsch:

```python
[for x in range(5)]
```

Richtig:

```python
[x for x in range(5)]
```

Vor dem `for` muss stehen, welcher Wert in die neue Liste aufgenommen werden soll.

## Filter und bedingten Ausdruck verwechseln

### Filtern

```python
[
    x
    for x in zahlen
    if x > 0
]
```

Nur passende Werte werden übernommen.

### Bedingter Ausdruck

```python
[
    "positiv" if x > 0 else "nicht positiv"
    for x in zahlen
]
```

Für jeden ursprünglichen Wert wird ein neuer Wert erzeugt.

## Zu viel Logik in eine List Comprehension schreiben

Eine List Comprehension wie

```python
ergebnis = [
    x * 2 if x % 3 == 0 else x ** 2
    for x in zahlen
    if x > 0 and x != 5
]
```

ist zwar möglich, aber nicht unbedingt gut lesbar.

Wenn beim Lesen zuerst entschlüsselt werden muss, was der Code überhaupt macht, ist eine normale Schleife oft die bessere Wahl.

# 14. Ein Denkmodell für List Comprehensions

Beim Erstellen einer List Comprehension helfen drei Fragen.

## 1. Welche Daten werden durchlaufen?

```python
for temperatur in temperaturen
```

## 2. Welche Elemente sollen verwendet werden?

Falls gefiltert werden soll:

```python
if temperatur < 0
```

## 3. Was soll in die neue Liste geschrieben werden?

Zum Beispiel:

```python
temperatur * 1.8 + 32
```

Zusammen ergibt das:

```python
[
    temperatur * 1.8 + 32
    for temperatur in temperaturen
    if temperatur < 0
]
```

Dieses Schema lässt sich auf viele Aufgaben übertragen.

## Übung 1 – Werte transformieren

Gegeben ist:

```python
zahlen = [2, 4, 6, 8]
```

Erzeuge mit einer List Comprehension eine neue Liste, in der jede Zahl verdreifacht wird.

Das Ergebnis soll sein:

```text
[6, 12, 18, 24]
```

### Lösungsschema

```text
1. Welche Daten werden durchlaufen?
   → zahlen

2. Wie heißt das aktuelle Element?
   → zum Beispiel zahl

3. Was soll mit jedem Element geschehen?
   → mit 3 multiplizieren

4. Wird ein Filter benötigt?
   → nein
```

Grundstruktur:

```python
[
    AUSDRUCK
    for ELEMENT in ITERABLE
]
```

```python
verdreifacht = [
    zahl * 3
    for zahl in zahlen
]

print(verdreifacht)
```

Ausgabe:

```text
[6, 12, 18, 24]
```

</details>

## Übung 2 – Filtern und transformieren

Gegeben sind folgende Temperaturen:

```python
temperaturen = [8.5, -3.0, 12.1, -7.2, 0.0, 5.4]
```

Erzeuge eine neue Liste, die nur Temperaturen unter 0 °C enthält.

Diese Temperaturen sollen gleichzeitig in Fahrenheit umgerechnet werden.

Formel:

```text
F = C * 1.8 + 32
```

### Lösungsschema

```text
1. Iterable:
   → temperaturen

2. Aktuelles Element:
   → temperatur

3. Filter:
   → temperatur < 0

4. Transformation:
   → temperatur * 1.8 + 32
```

Setze die Bestandteile in dieses Schema ein:

```python
[
    TRANSFORMATION
    for ELEMENT in ITERABLE
    if BEDINGUNG
]
```

<details>
<summary>Vollständige Lösung anzeigen</summary>

```python
frost_fahrenheit = [
    temperatur * 1.8 + 32
    for temperatur in temperaturen
    if temperatur < 0
]

print(frost_fahrenheit)
```

Ausgabe ungefähr:

```text
[26.6, 19.04]
```

</details>

## Übung 3 – Bedingten Wert erzeugen

Gegeben ist:

```python
temperaturen = [4, -2, 0, -5, 8]
```

Erzeuge für jede Temperatur einen String:

- `"Frost"` bei Temperaturen unter 0
- `"kein Frost"` bei allen anderen Temperaturen

Erwartetes Ergebnis:

```text
['kein Frost', 'Frost', 'kein Frost', 'Frost', 'kein Frost']
```

### Lösungsschema

Hier dürfen keine Werte entfernt werden.

Für jede Temperatur muss genau ein neuer Wert entstehen.

```text
1. Iterable:
   → temperaturen

2. Aktuelles Element:
   → temperatur

3. Bedingung:
   → temperatur < 0

4. Wert bei True:
   → "Frost"

5. Wert bei False:
   → "kein Frost"
```

Verwende deshalb dieses Schema:

```python
[
    WERT_TRUE if BEDINGUNG else WERT_FALSE
    for ELEMENT in ITERABLE
]
```

<details>
<summary>Vollständige Lösung anzeigen</summary>

```python
status = [
    "Frost" if temperatur < 0 else "kein Frost"
    for temperatur in temperaturen
]

print(status)
```

</details>

## Übung 4 – Verschachtelte Daten

Gegeben sind Messwerte aus mehreren Tagen:

```python
messwerte = [
    [12, 14, 13],
    [10, 11, 12],
    [15, 16, 14]
]
```

Erzeuge daraus eine einzige Liste:

```text
[12, 14, 13, 10, 11, 12, 15, 16, 14]
```

### Lösungsschema

Überlege zuerst, wie die Aufgabe mit normalen Schleifen aussehen würde:

```python
for tageswerte in messwerte:
    for wert in tageswerte:
        ...
```

Bei der List Comprehension bleiben die `for`-Teile in derselben Reihenfolge:

```python
[
    AUSDRUCK
    for tageswerte in messwerte
    for wert in tageswerte
]
```

Welcher Ausdruck muss vorne stehen?

Der einzelne `wert`.

<details>
<summary>Vollständige Lösung anzeigen</summary>

```python
alle_messwerte = [
    wert
    for tageswerte in messwerte
    for wert in tageswerte
]

print(alle_messwerte)
```

Ausgabe:

```text
[12, 14, 13, 10, 11, 12, 15, 16, 14]
```

</details>

# Zusammenfassung

## Iterable

Ein Iterable ist ein Objekt, dessen Elemente nacheinander durchlaufen werden können.

Beispiele:

```python
[1, 2, 3]
(1, 2, 3)
range(10)
"Python"
```

## Einfache List Comprehension

```python
[
    ausdruck
    for element in iterable
]
```

Beispiel:

```python
[
    x * 2
    for x in zahlen
]
```

## Filtern

```python
[
    element
    for element in iterable
    if bedingung
]
```

Beispiel:

```python
[
    x
    for x in zahlen
    if x > 0
]
```

## Transformieren und filtern

```python
[
    ausdruck
    for element in iterable
    if bedingung
]
```

Beispiel:

```python
[
    x ** 2
    for x in zahlen
    if x > 0
]
```

## Bedingten Wert erzeugen

```python
[
    wert_true if bedingung else wert_false
    for element in iterable
]
```

Beispiel:

```python
[
    "gerade" if x % 2 == 0 else "ungerade"
    for x in zahlen
]
```

---

## Merksatz

Bei einer List Comprehension helfen meist drei Fragen:

```text
Welche Daten durchlaufe ich?

Welche Elemente brauche ich?

Was soll aus diesen Elementen werden?
```

Aus diesen drei Fragen entsteht beispielsweise:

```python
[
    temperatur * 1.8 + 32
    for temperatur in temperaturen
    if temperatur < 0
]
```

List Comprehensions sind kein Ersatz für jede Schleife.

Sie sind besonders dann sinnvoll, wenn sich das Erzeugen einer neuen Liste **kurz und verständlich** ausdrücken lässt.
