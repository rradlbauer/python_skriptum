# 2. Iterables und Iteratoren

Viele eingebaute Funktionen arbeiten mit **Iterables**.

Ein Iterable ist ein Objekt, dessen Elemente nacheinander durchlaufen werden können.

Beispiele:

```python
zahlen = [1, 2, 3]           # Liste
punkt = (4, 7)               # Tupel
wort = "Python"              # String
werte = {10, 20, 30}         # Set
person = {"name": "Mia"}     # Dictionary
bereich = range(5)           # range-Objekt
```

Alle diese Objekte können beispielsweise mit einer `for`-Schleife durchlaufen werden.

```python
for zahl in zahlen:
    print(zahl)
```

---

## Iterator

Ein **Iterator** liefert Werte nacheinander.

Ein Iterator kann ebenfalls mit einer `for`-Schleife durchlaufen werden:

```python
iterator = iter([10, 20, 30])

for wert in iterator:
    print(wert)
```

Einige eingebaute Funktionen wie

- `zip()`
- `map()`
- `filter()`
- `reversed()`

geben Iteratoren bzw. spezielle Iteratorobjekte zurück.

Möchte man deren Werte sofort als Liste sehen, kann man `list()` verwenden:

```python
iterator = reversed([1, 2, 3])

print(list(iterator))
```

Ausgabe:

```text
[3, 2, 1]
```

Das bedeutet aber nicht, dass man immer `list()` verwenden muss.

Sehr oft wird ein Iterator direkt in einer Schleife verarbeitet:

```python
for zahl in reversed([1, 2, 3]):
    print(zahl)
```

# 3. `abs()` – Abstand von null

Die Funktion `abs()` liefert den **Absolutwert** einer Zahl.

Bei reellen Zahlen kann man sich den Absolutwert als Abstand von `0` auf der Zahlengeraden vorstellen.

```python
print(abs(-5))
print(abs(3.14))
```

Ausgabe:

```text
5
3.14
```

Für die Wetterstation können wir damit beispielsweise bestimmen, wie weit eine Temperatur von `0 °C` entfernt ist:

```python
temperatur = -4.7

abstand_von_null = abs(temperatur)

print(abstand_von_null)
```

Ausgabe:

```text
4.7
```

Das Vorzeichen spielt für den Abstand keine Rolle.

# 4. `round()` – Zahlen runden

Die Funktion `round()` rundet eine Zahl.

Ohne zweites Argument wird auf eine ganze Zahl gerundet:

```python
print(round(3.14159))
```

Ausgabe:

```text
3
```

Mit einem zweiten Argument kann die Anzahl der Nachkommastellen angegeben werden:

```python
print(round(3.14159, 2))
```

Ausgabe:

```text
3.14
```

Für unsere Messwerte:

```python
temperaturen = [4.26, -1.75, 7.82, 11.34, 5.09]

gerundet = [
    round(temperatur, 1)
    for temperatur in temperaturen
]

print(gerundet)
```

Ausgabe:

```text
[4.3, -1.8, 7.8, 11.3, 5.1]
```

---

## Achtung bei Zahlen genau zwischen zwei Ganzzahlen

Python verwendet beim Runden von exakten Halbwerten die Regel:

> Liegt der Wert genau zwischen zwei Möglichkeiten, wird zur **geraden** Zahl gerundet.

Zum Beispiel:

```python
print(round(2.5))
print(round(3.5))
```

Ausgabe:

```text
2
4
```

Das unterscheidet sich von der oft in der Schule verwendeten Regel „ab 5 wird aufgerundet“.

Zusätzlich werden `float`-Zahlen intern binär gespeichert. Dadurch können bei bestimmten Dezimalzahlen Rundungsergebnisse auftreten, die zunächst überraschend wirken.

Für normale Messwerte genügt meist:

```python
round(wert, anzahl_nachkommastellen)
```

Bei exakten Geld- oder Dezimalrechnungen können später speziellere Datentypen wie `Decimal` sinnvoll sein.

# 5. `sorted()` – Daten sortieren

`sorted()` sortiert die Elemente eines Iterables und gibt eine **neue Liste** zurück.

```python
zahlen = [5, 2, 9, 1, 5, 6]

sortiert = sorted(zahlen)

print(sortiert)
```

Ausgabe:

```text
[1, 2, 5, 5, 6, 9]
```

Die ursprüngliche Liste wird dabei nicht verändert:

```python
print(zahlen)
```

Ausgabe:

```text
[5, 2, 9, 1, 5, 6]
```

Das ist ein wichtiger Unterschied zur Listenmethode `sort()`:

```python
zahlen.sort()
```

`sort()` verändert die vorhandene Liste.

`sorted()` erzeugt dagegen eine neue Liste.

---

## Absteigend sortieren

Mit `reverse=True` kann absteigend sortiert werden:

```python
temperaturen = [4.26, -1.75, 7.82, 11.34, 5.09]

absteigend = sorted(temperaturen, reverse=True)

print(absteigend)
```

Ausgabe:

```text
[11.34, 7.82, 5.09, 4.26, -1.75]
```

---

## Mit `key` nach einem bestimmten Kriterium sortieren

`sorted()` kann zusätzlich eine Funktion erhalten, die bestimmt, **wonach** sortiert wird.

Beispiel:

```python
woerter = ["Python", "KI", "Programm", "Code"]

nach_laenge = sorted(woerter, key=len)

print(nach_laenge)
```

Ausgabe:

```text
['KI', 'Code', 'Python', 'Programm']
```

Hier wird nicht alphabetisch, sondern nach der Länge der Strings sortiert.

# 6. `reversed()` – rückwärts durchlaufen

`reversed()` erzeugt einen Iterator, der die Elemente in umgekehrter Reihenfolge liefert.

```python
zahlen = [1, 2, 3, 4, 5]

rueckwaerts = reversed(zahlen)

print(list(rueckwaerts))
```

Ausgabe:

```text
[5, 4, 3, 2, 1]
```

Häufig benötigt man gar keine neue Liste:

```python
for zahl in reversed(zahlen):
    print(zahl)
```

`reversed()` funktioniert mit Objekten, die eine umgekehrte Reihenfolge unterstützen, beispielsweise Listen, Tupeln, Strings und `range`-Objekten.

Es ist daher genauer, von **umkehrbaren Objekten** zu sprechen und nicht davon, dass `reversed()` mit jedem beliebigen Iterable funktioniert.

Beispiel mit einem String:

```python
wort = "Python"

print("".join(reversed(wort)))
```

Ausgabe:

```text
nohtyP
```

# 7. `enumerate()` – Position und Wert gleichzeitig

Bei einer Schleife benötigt man manchmal sowohl

- das aktuelle Element
- als auch seine Position.

Dafür gibt es `enumerate()`.

Ohne `enumerate()` könnte man beispielsweise schreiben:

```python
temperaturen = [4.2, 5.1, 7.8]

for index in range(len(temperaturen)):
    print(index, temperaturen[index])
```

Mit `enumerate()` ist die Absicht klarer:

```python
temperaturen = [4.2, 5.1, 7.8]

for index, temperatur in enumerate(temperaturen):
    print(index, temperatur)
```

Ausgabe:

```text
0 4.2
1 5.1
2 7.8
```

Standardmäßig beginnt die Zählung bei `0`.

Mit `start` kann ein anderer Startwert angegeben werden:

```python
for nummer, temperatur in enumerate(temperaturen, start=1):
    print(nummer, temperatur)
```

Ausgabe:

```text
1 4.2
2 5.1
3 7.8
```

Das ist beispielsweise praktisch, wenn Messungen für Menschen ab `1` nummeriert werden sollen.

# 8. `zip()` – zusammengehörige Daten verbinden

Unsere Wetterstation hat bisher zwei Listen:

```python
zeiten = ["08:00", "10:00", "12:00", "14:00", "16:00"]
temperaturen = [4.26, -1.75, 7.82, 11.34, 5.09]
```

Die Werte an derselben Position gehören zusammen:

```text
08:00 → 4.26
10:00 → -1.75
12:00 → 7.82
...
```

Mit `zip()` können mehrere Iterables gemeinsam durchlaufen werden:

```python
for zeit, temperatur in zip(zeiten, temperaturen):
    print(zeit, temperatur)
```

Ausgabe:

```text
08:00 4.26
10:00 -1.75
12:00 7.82
14:00 11.34
16:00 5.09
```

`zip()` liefert Tupel.

Mit `list()` können wir diese sichtbar machen:

```python
messungen = list(zip(zeiten, temperaturen))

print(messungen)
```

Ausgabe:

```text
[
    ('08:00', 4.26),
    ('10:00', -1.75),
    ('12:00', 7.82),
    ('14:00', 11.34),
    ('16:00', 5.09)
]
```

---

## Unterschiedliche Längen

Standardmäßig endet `zip()`, sobald das kürzeste Iterable keine weiteren Elemente mehr besitzt.

```python
namen = ["Anna", "Ben", "Clara"]
punkte = [12, 9]

print(list(zip(namen, punkte)))
```

Ausgabe:

```text
[('Anna', 12), ('Ben', 9)]
```

`"Clara"` wird nicht mehr verarbeitet.

Wenn die Listen eigentlich gleich lang sein **müssen**, ist das leicht zu übersehen.

Moderne Python-Versionen bieten dafür `strict=True`:

```python
list(zip(namen, punkte, strict=True))
```

Bei unterschiedlich langen Iterables wird dann ein `ValueError` ausgelöst.

Das ist besonders nützlich, wenn unterschiedliche Längen auf einen Fehler in den Daten hindeuten.

# 9. `map()` – eine Funktion auf viele Werte anwenden

`map()` wendet eine Funktion nacheinander auf Elemente eines oder mehrerer Iterables an.

Die Funktion gibt einen Iterator zurück.

Beispiel:

```python
def quadriere(x):
    return x ** 2


zahlen = [1, 2, 3, 4, 5]

quadrate = map(quadriere, zahlen)

print(list(quadrate))
```

Ausgabe:

```text
[1, 4, 9, 16, 25]
```

Für unsere Wetterstation:

```python
def celsius_zu_fahrenheit(celsius):
    return celsius * 1.8 + 32


temperaturen = [0, 10, 20]

fahrenheit = map(celsius_zu_fahrenheit, temperaturen)

print(list(fahrenheit))
```

Ausgabe:

```text
[32.0, 50.0, 68.0]
```

---

## `map()` oder List Comprehension?

Aus dem vorherigen Kapitel kennst du bereits List Comprehensions.

Dasselbe Beispiel kann so geschrieben werden:

```python
fahrenheit = [
    celsius_zu_fahrenheit(temperatur)
    for temperatur in temperaturen
]
```

Beide Varianten sind möglich.

Für einfache Transformationen ist eine List Comprehension in Python häufig leichter zu lesen.

`map()` kann besonders praktisch sein, wenn bereits eine passende Funktion vorhanden ist und diese direkt auf alle Werte angewendet werden soll.

# 10. `filter()` – Werte auswählen

`filter()` verwendet eine Funktion, um zu entscheiden, welche Elemente übernommen werden.

Die verwendete Funktion sollte für jedes Element einen Wahrheitswert liefern.

Beispiel:

```python
def ist_gerade(x):
    return x % 2 == 0


zahlen = [1, 2, 3, 4, 5]

gerade = filter(ist_gerade, zahlen)

print(list(gerade))
```

Ausgabe:

```text
[2, 4]
```

Für die Wetterstation:

```python
def ist_frost(temperatur):
    return temperatur < 0


temperaturen = [4.26, -1.75, 7.82, -3.4]

frostwerte = filter(ist_frost, temperaturen)

print(list(frostwerte))
```

Ausgabe:

```text
[-1.75, -3.4]
```

---

## `filter()` oder List Comprehension?

Mit einer List Comprehension:

```python
frostwerte = [
    temperatur
    for temperatur in temperaturen
    if temperatur < 0
]
```

Auch hier sind beide Schreibweisen möglich.

Als Orientierung:

```text
map()     → Werte transformieren
filter()  → Werte auswählen
```

Mit List Comprehensions kann man beide Aufgaben ebenfalls ausdrücken:

```python
# Transformation
[ausdruck for element in iterable]

# Filter
[element for element in iterable if bedingung]
```

# 11. `any()` und `all()` – mehrere Bedingungen zusammenfassen

Manchmal interessiert uns nicht die Liste aller passenden Werte, sondern nur eine Ja-Nein-Frage.

Zum Beispiel:

> Gab es überhaupt Frost?

Dafür eignet sich `any()`.

```python
temperaturen = [4.2, 3.8, -1.5, 6.0]

frost_vorhanden = any(
    temperatur < 0
    for temperatur in temperaturen
)

print(frost_vorhanden)
```

Ausgabe:

```text
True
```

`any()` liefert `True`, wenn **mindestens ein** Element wahr ist.

---

## Sind alle Bedingungen erfüllt?

`all()` liefert `True`, wenn **alle** Elemente wahr sind.

Beispiel:

```python
temperaturen = [4.2, 3.8, 1.5, 6.0]

alle_ueber_null = all(
    temperatur > 0
    for temperatur in temperaturen
)

print(alle_ueber_null)
```

Ausgabe:

```text
True
```

Ein hilfreicher Merksatz:

```text
any() → mindestens eines?
all() → wirklich alle?
```

# 12. `isinstance()` – Datentypen überprüfen

Mit `isinstance()` kann überprüft werden, ob ein Objekt zu einem bestimmten Datentyp gehört.

```python
print(isinstance(42, int))
print(isinstance("Hallo", str))
print(isinstance(3.14, float))
print(isinstance([1, 2, 3], list))
```

Ausgabe:

```text
True
True
True
True
```

Das kann beispielsweise bei eingelesenen oder gemischten Daten hilfreich sein:

```python
messwert = 12.5

if isinstance(messwert, float):
    print("Der Messwert ist eine Fließkommazahl.")
```

---

## Mehrere erlaubte Typen

`isinstance()` kann auch mehrere erlaubte Typen prüfen.

Dafür werden die Typen als Tupel angegeben:

```python
wert = 12

if isinstance(wert, (int, float)):
    print("Der Wert ist eine Zahl.")
```

Das ist häufig besser als:

```python
if type(wert) == int or type(wert) == float:
    ...
```

`isinstance()` berücksichtigt nämlich auch Vererbungsbeziehungen zwischen Klassen.

In der Ausgabe finden sich Listenmethoden wie:

# 14. `globals()` und `locals()` – Namensräume untersuchen

Python verwaltet Variablen in sogenannten **Namensräumen**.

Zwei eingebaute Funktionen erlauben einen Blick darauf:

- `globals()`
- `locals()`

Diese Funktionen werden im normalen Anfängerprogrammieren eher selten benötigt, sind aber nützlich, um das Verhalten von Variablen besser zu verstehen.

---

## `globals()`

`globals()` liefert ein Dictionary mit dem aktuellen globalen Namensraum.

```python
temperatur = 12.5

globale_namen = globals()

print(globale_namen["temperatur"])
```

Ausgabe:

```text
12.5
```

In einem normalen Python-Skript befinden sich darin zusätzlich viele automatisch erzeugte Namen wie:

```text
__name__
__file__
__builtins__
```

Darum ist eine vollständige Ausgabe von

```python
print(globals())
```

meist sehr lang und wenig übersichtlich.

---

## `locals()`

`locals()` liefert Informationen über den aktuellen lokalen Namensraum.

Innerhalb einer Funktion:

```python
def berechne():
    temperatur = 12.5
    einheit = "°C"

    print(locals())


berechne()
```

Eine mögliche Ausgabe ist:

```text
{'temperatur': 12.5, 'einheit': '°C'}
```

Damit lässt sich beispielsweise untersuchen, welche lokalen Variablen in einer Funktion aktuell existieren.

> `globals()` und `locals()` sollten zunächst vor allem als Werkzeuge zum Untersuchen eines Programms verstanden werden. Man sollte nicht versuchen, normalen Programmcode durch direktes Manipulieren dieser Dictionaries zu ersetzen.

# 15. Welche Funktion passt zu welcher Aufgabe?

Unsere Wetterstation hat mittlerweile mehrere typische Aufgaben gelöst.

Gegeben:

```python
zeiten = ["08:00", "10:00", "12:00", "14:00", "16:00"]
temperaturen = [4.26, -1.75, 7.82, 11.34, 5.09]
```

```python
gerundet = [
    round(temperatur, 1)
    for temperatur in temperaturen
]
```

## Temperaturen sortieren

```python
sortiert = sorted(temperaturen)
```

## Höchste Temperatur

```python
hoechste = max(temperaturen)
```

## Niedrigste Temperatur

```python
niedrigste = min(temperaturen)
```

```python
messungen = list(zip(zeiten, temperaturen))
```

```python
frost_vorhanden = any(
```

```python
nur_zahlen = all(
```

Wir müssen also nicht für jede kleine Standardaufgabe selbst eine neue Funktion programmieren.

# 16. Rückgabewerte im Überblick

Nicht alle eingebauten Funktionen liefern dieselbe Art von Ergebnis.

| Funktion | Typisches Ergebnis |
|---|---|
| `abs()` | Zahl |
| `round()` | Zahl |
| `sorted()` | neue Liste |
| `reversed()` | Iterator |
| `enumerate()` | Iterator |
| `zip()` | Iterator |
| `map()` | Iterator |
| `filter()` | Iterator |
| `any()` | `bool` |
| `all()` | `bool` |
| `isinstance()` | `bool` |
| `dir()` | Liste von Namen |
| `globals()` | Dictionary |
| `locals()` | Mapping bzw. Dictionary-ähnliche Darstellung des aktuellen Namensraums |

Gerade bei Iteratoren ist wichtig:

```python
ergebnis = map(funktion, daten)
```

liefert nicht direkt eine Liste.

Falls tatsächlich eine Liste benötigt wird:

```python
ergebnis = list(map(funktion, daten))
```

Für eine Schleife ist die Umwandlung dagegen nicht nötig:

```python
for wert in map(funktion, daten):
    print(wert)
```

# 17. Typische Fehler und Missverständnisse

## `sorted()` und `sort()` verwechseln

`sorted()`:

```python
zahlen = [3, 1, 2]

neu = sorted(zahlen)

print(zahlen)
print(neu)
```

Ausgabe:

```text
[3, 1, 2]
[1, 2, 3]
```

`sort()`:

```python
zahlen.sort()
```

verändert dagegen die vorhandene Liste.

---

## Von `zip()`, `map()` oder `filter()` direkt eine Liste erwarten

```python
zahlen = [1, 2, 3]

ergebnis = map(str, zahlen)

print(ergebnis)
```

Die Ausgabe zeigt nicht einfach:

```text
['1', '2', '3']
```

Denn `map()` liefert einen Iterator.

Soll eine Liste erzeugt werden:

```python
print(list(ergebnis))
```

---

## `zip()` mit unterschiedlich langen Listen unbemerkt verwenden

```python
namen = ["Anna", "Ben", "Clara"]
punkte = [10, 8]

print(list(zip(namen, punkte)))
```

`Clara` verschwindet aus dem Ergebnis, weil die kürzere Liste endet.

Wenn beide Listen gleich lang sein müssen:

```python
list(zip(namen, punkte, strict=True))
```

---

## `reversed()` mit jedem Iterable erwarten

Nicht jedes Iterable unterstützt `reversed()`.

Ein `set` besitzt beispielsweise keine feste Reihenfolge, die einfach rückwärts durchlaufen werden könnte.

```python
werte = {1, 2, 3}
```

Für geordnete Objekte wie Listen, Tupel, Strings oder `range` ist `reversed()` dagegen typisch.

---

## `round()` mit der Schulregel gleichsetzen

```python
print(round(2.5))
```

liefert:

```text
2
```

und

```python
print(round(3.5))
```

liefert:

```text
4
```

Python rundet exakte Halbwerte also nicht immer einfach nach oben.

## Übung 1 – Messdaten aufbereiten

Gegeben sind folgende Temperaturen:

```python
temperaturen = [6.82, -2.14, 10.49, 3.05, -5.71]
```

Erzeuge:

1. eine neue, auf eine Nachkommastelle gerundete Liste,
2. eine aufsteigend sortierte Liste der ursprünglichen Messwerte,
3. einen Wahrheitswert, der angibt, ob mindestens eine Temperatur unter `0` liegt.

### Lösungsschema

Ordne jeder Teilaufgabe zunächst die passende Funktion zu:

```text
Runden
→ round()

Sortieren
→ sorted()

Mindestens ein passender Wert?
→ any()
```

Für das Runden benötigen wir die Funktion für **jeden einzelnen Messwert**:

```text
für jede temperatur:
    round(temperatur, 1)
```

Für die Frostprüfung benötigen wir für jeden Wert eine Bedingung:

```text
temperatur < 0
```

und anschließend:

```text
any(...)
```

<details>
<summary>Vollständige Lösung anzeigen</summary>

```python
temperaturen = [6.82, -2.14, 10.49, 3.05, -5.71]

gerundet = [
    round(temperatur, 1)
    for temperatur in temperaturen
]

sortiert = sorted(temperaturen)

frost_vorhanden = any(
    temperatur < 0
    for temperatur in temperaturen
)

print(gerundet)
print(sortiert)
print(frost_vorhanden)
```

Ausgabe:

```text
[6.8, -2.1, 10.5, 3.0, -5.7]
[-5.71, -2.14, 3.05, 6.82, 10.49]
True
```

</details>

## Übung 2 – Zwei Datenreihen verbinden

Gegeben sind:

```python
namen = ["Anna", "Ben", "Clara", "David"]
punkte = [15, 9, 18, 12]
```

Gib die Daten in folgender Form aus:

```text
1. Anna: 15 Punkte
2. Ben: 9 Punkte
3. Clara: 18 Punkte
4. David: 12 Punkte
```

Verwende dafür `zip()` und `enumerate()`.

### Lösungsschema

Zuerst müssen Name und Punktewert zusammengeführt werden:

```text
namen + punkte
→ zip(namen, punkte)
```

Dadurch entstehen gedanklich Paare:

```text
("Anna", 15)
("Ben", 9)
...
```

Anschließend sollen diese Paare nummeriert werden:

```text
enumerate(..., start=1)
```

Die Schleife benötigt dadurch drei Werte:

```text
nummer
name
punktewert
```

<details>
<summary>Vollständige Lösung anzeigen</summary>

```python
namen = ["Anna", "Ben", "Clara", "David"]
punkte = [15, 9, 18, 12]

for nummer, (name, punktewert) in enumerate(
    zip(namen, punkte),
    start=1
):
    print(f"{nummer}. {name}: {punktewert} Punkte")
```

Ausgabe:

```text
1. Anna: 15 Punkte
2. Ben: 9 Punkte
3. Clara: 18 Punkte
4. David: 12 Punkte
```

Die Klammern bei

```python
(name, punktewert)
```

zeigen, dass das von `zip()` erzeugte Tupel direkt in zwei Variablen zerlegt wird.

</details>

## Übung 3 – `map()`, `filter()` und List Comprehension vergleichen

Gegeben ist:

```python
temperaturen = [5, -3, 8, -1, 12]
```

Erzeuge zuerst mit `filter()` eine Liste aller Frostwerte.

Wandle anschließend dieselben Frostwerte mit `map()` in Fahrenheit um.

Verwende:

```text
F = C * 1.8 + 32
```

Schreibe danach dieselbe Verarbeitung noch einmal als **eine einzige List Comprehension**.

### Lösungsschema

Für `filter()` benötigen wir eine Funktion mit einer Bedingung:

```text
temperatur < 0
```

Für `map()` benötigen wir eine Transformationsfunktion:

```text
temperatur * 1.8 + 32
```

Der Ablauf lautet also:

```text
temperaturen
    ↓
filter()
    ↓
nur Frostwerte
    ↓
map()
    ↓
Fahrenheit-Werte
```

Bei einer List Comprehension können Filter und Transformation direkt kombiniert werden:

```python
[
    TRANSFORMATION
    for ELEMENT in ITERABLE
    if BEDINGUNG
]
```

<details>
<summary>Vollständige Lösung anzeigen</summary>

```python
temperaturen = [5, -3, 8, -1, 12]


def ist_frost(temperatur):
    return temperatur < 0


def celsius_zu_fahrenheit(celsius):
    return celsius * 1.8 + 32


frostwerte = list(
    filter(ist_frost, temperaturen)
)

frost_fahrenheit = list(
    map(celsius_zu_fahrenheit, frostwerte)
)

print(frost_fahrenheit)
```

Ausgabe:

```text
[26.6, 30.2]
```

Dasselbe mit einer List Comprehension:

```python
frost_fahrenheit = [
    temperatur * 1.8 + 32
    for temperatur in temperaturen
    if temperatur < 0
]

print(frost_fahrenheit)
```

Beide Varianten sind korrekt.

Die List Comprehension ist für diese einfache Kombination meist kompakter und direkt lesbar.

</details>

# Zusammenfassung

Python stellt viele **eingebaute Funktionen und Typen** bereit, die ohne zusätzlichen Import verfügbar sind.

Eine vollständige Übersicht findest du in der offiziellen Dokumentation:

[Python-Dokumentation: Built-in Functions](https://docs.python.org/3/library/functions.html)

## Wichtige Funktionen aus diesem Kapitel

| Funktion | Aufgabe |
|---|---|
| `abs(x)` | Absolutwert berechnen |
| `round(x, n)` | Zahl runden |
| `sorted(iterable)` | neue sortierte Liste erzeugen |
| `reversed(objekt)` | Objekt rückwärts durchlaufen |
| `enumerate(iterable)` | Position und Wert gemeinsam liefern |
| `zip(a, b)` | Elemente mehrerer Iterables verbinden |
| `map(funktion, iterable)` | Funktion auf Elemente anwenden |
| `filter(funktion, iterable)` | passende Elemente auswählen |
| `any(iterable)` | prüfen, ob mindestens ein Wert wahr ist |
| `all(iterable)` | prüfen, ob alle Werte wahr sind |
| `isinstance(objekt, typ)` | Datentyp überprüfen |
| `dir(objekt)` | Namen eines Objekts untersuchen |
| `globals()` | globalen Namensraum untersuchen |
| `locals()` | lokalen Namensraum untersuchen |

---

## Wichtige Begriffe

### Eingebaute Funktion

Eine Funktion, die von Python direkt bereitgestellt wird und normalerweise ohne `import` verwendet werden kann.

### `builtins`

Das Modul, in dem die eingebauten Namen von Python bereitgestellt werden.

### Iterable

Ein Objekt, dessen Elemente nacheinander durchlaufen werden können.

### Iterator

Ein Objekt, das Werte nacheinander liefert.
